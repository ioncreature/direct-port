# DirectPort — бренд-ассеты

Логотип, знаки и favicon. Здесь и финальные выбранные ассеты, и архив концепций,
которые перебирали по пути. Каждый SVG самодостаточен (текст в кривых), PNG отрендерены
из SVG через `sharp`.

## Что выбрано (финал)

- **Вордмарк:** `direct_port` — моноширинный, строчными, с оранжевым подчёркиванием-связкой.
  На лендинге это **живой текст** (шрифт JetBrains Mono через `next/font`), а не картинка,
  поэтому отдельного SVG-вордмарка здесь нет — только спецификация ниже.
- **Favicon:** `favicon/svg/favicon-cursor.svg` — строчная `d` + оранжевая вертикальная
  черта-курсор («приглашение терминала»). Высота черты пока не зафиксирована — рядом лежат
  три варианта (см. ниже).

### Спецификация вордмарка

| Часть | Цвет | Hex |
|---|---|---|
| `direct` | нави | `#0B2536` |
| `_` (подчёркивание) | оранжевый | `#E8622A` |
| `port` | петроль | `#0F6E7C` |

Начертание: JetBrains Mono, вес ~600, регистр строчный, трекинг ≈ −0.02em.

## Палитра

| Роль | Название | Hex |
|---|---|---|
| Основной / текст | Глубокий морской нави | `#0B2536` |
| Вторичный | Петроль | `#0F6E7C` |
| Акцент | Сигнальный оранжевый | `#E8622A` |
| Фон | Тёплый туманно-белый | `#F6F4EF` |

Премиум-альтернатива (латунь): нави `#101C28`, латунь `#C0912F`, бумага `#F4EFE6`.

## Структура

```
brand/
  favicon/
    svg/  favicon-cursor.svg            ← финал (черта во всю высоту)
          favicon-cursor-xheight.svg    вариант: курсор по x-высоте
          favicon-cursor-block.svg      вариант: широкий блок-курсор
          favicon-cursor-light.svg      на светлом фоне
          favicon-cursor-mono.svg       без плитки, прозрачный фон
          favicon-farvater*.svg         архив: отклонённый знак «Фарватер»
          favicon-porthole*.svg         архив: отклонённый знак «Иллюминатор»
    png/  <base>-{512,180,64,32,16}.png
  logo/
    svg/  logo-farvater*.svg   стрелка в гавань (партия 1, отклонён)
          logo-gateway.svg     ворота/гейт (отклонён)
          logo-container.svg   контейнер (отклонён)
          logo-stamp.svg       печать (отклонён)
          logo-harbour.svg     гавань без стрелки (отклонён)
          logo-stack.svg       штабель контейнеров (2-й фаворит)
          logo-porthole*.svg   иллюминатор / лигатура pOrt (фаворит среди знаков)
          logo-slot.svg        скобки-слот (отклонён)
          logo-crane.svg       портовый кран (отклонён)
    png/  лок-апы — {base}.png (1200px по ширине)
          символы — {base}-{512,180,64,32,16}.png
```

Пометки «отклонён / фаворит» — статус на момент выбора вордмарка. Знак-картинку решили
пока не ставить: бренд держится на моно-вордмарке и favicon-курсоре. Лок-апы со знаками
оставлены в архиве на случай, если позже захотим добавить символ (лучший из них — `logo-porthole-ligature`).

## Регенерация PNG

PNG собираются из SVG скриптом на `sharp` (мастер-растр 2048px → ресайз). Скрипт разовый,
лежал в `temp/` (не в репозитории). При необходимости — отрендерить заново любым SVG→PNG
конвертером; размеры: favicon 512/180/64/32/16, лок-апы — ширина 1200.
