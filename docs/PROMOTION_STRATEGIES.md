# Стратегии продвижения DirectPort

Дата: 16.07.2026. Статус: рабочий план.

Документ самодостаточен — его можно отдать как бриф маркетологу / помощнику по
продвижению. Контекст, диагноз, сегменты, каналы, приоритеты и внутренние
инструменты, которые уже есть в продукте.

## Продукт и оффер

DirectPort (directport.ru) — сервис расчёта таможенных платежей для импортёров.
Клиент присылает прайс/инвойс (до ~500 позиций, хоть на китайском) — через
10 минут получает Excel: коды ТН ВЭД, пошлины, НДС, акцизы, разрешительные
документы, черновик декларации («Проект ДТ»), чек-лист документов к поставке,
выгрузку для декларантского ПО (Контур.Декларант / Альта / СТМ). Вручную
декларант тратит на это дни.

**Оффер для всех каналов:** «Пришлите инвойс — вернём готовый расчёт сегодня.
Первые 50 позиций — бесплатно». Демо вместо питча: себестоимость демо
копеечная, готовый Excel продаёт лучше любого рассказа о продукте.

Цена: $1/позиция (контейнер — $100–500 за расчёт).

## Диагноз: почему холодные звонки не сработали

Проведено ~11 звонков в логистические компании — 0 результатов. Это не сигнал
о продукте:

1. **Статистика.** Конверсия холодного звонка во встречу — 1–5%. 11 звонков —
   ~0,3 ожидаемой встречи. Выборка ничего не измерила.
2. **Точка входа.** Горячая линия = гейткипер, который отправляет «предложения»
   на info@. info@ — чёрная дыра.
3. **Несоответствие канала продукту.** Чек $100–500 не окупает трудоёмкие
   исходящие продажи в лоб. ЛПР — конкретный человек (декларант, специалист
   по ВЭД, владелец карго, селлер), а не «компания». Эти люди сидят в
   Telegram-чатах и гуглят «калькулятор таможенных платежей» — там их и брать.

## Сегменты ЦА (по теплоте)

1. **Селлеры маркетплейсов, переходящие на белый импорт** — самый горячий и
   массовый сегмент. Возят из Китая, боятся таможни, декларанта нет, живут в
   Telegram, привыкли к self-service. Кабинет + free-50 — ровно под них.
2. **Карго-компании / «доставка из Китая под ключ»** — нужен быстрый просчёт
   для КП клиентам; сервис экономит часы на каждое КП.
3. **Таможенные брокеры и декларанты** — инструмент ускорения (есть выгрузка
   в их ПО). Консервативны, но реестр таможенных представителей ФТС — публичный
   список с контактами.
4. **Отделы ВЭД импортёров-оптовиков** — идеальный клиент, но самый длинный
   цикл сделки.

## Каналы подробно

### Полностью автоматические

**1. Яндекс.Директ на транзакционные запросы.** «Калькулятор таможенных
платежей», «расчёт пошлины ТН ВЭД онлайн», «растаможка из Китая стоимость» —
люди с болью прямо сейчас. Лендинг и оффер free-50 готовы. Тест —
30–50 тыс. ₽/мес, дальше по CAC. Самый быстрый платный канал.

**2. Программатик-SEO из данных TKS.** Тысячи страниц вида «Пошлина на
<товар> из Китая в 2026: код ТН ВЭД, ставка, НДС, утильсбор, маркировка ЧЗ,
разрешительные документы» по топ-кодам/товарам. Уникальный структурированный
контент (сертификация + ЧЗ-волны + утильсбор в одном месте) уже лежит в
TKS-кэше и curated-слое. Отдача через 3–6 месяцев, работает вечно.

**3. Публичный мини-калькулятор на лендинге.** ✅ Реализован (07.2026). Один
товар без регистрации → «весь контейнер — в боте, 50 позиций бесплатно».
Конвертер для трафика из п. 1–2. Отдельная страница `/calculator`
(+ `/en/calculator`, `/zh/calculator`) с SEO-метой под транзакционные запросы
(«калькулятор таможенных платежей» — посадочная для Директа из п. 1); на
главной — тизер-секция со ссылкой + пункт «Калькулятор» в меню. Форма:
описание/код ТН ВЭД + стоимость → код, ставки, платежи в ₽, альтернативные
коды, CTA в бота. Backend — `POST /public/calculator/estimate` (rate-limit по
IP, `PUBLIC_CALC_HOURLY_LIMIT`); в проде лендингу нужен env `CALC_API_URL`
(внутренний адрес api).

**4. Автоматический email-outbound на существующем leads-пайплайне.**
Discovery (web_search по городу/нише) и enrichment (emails, ИНН,
relevanceScore, relevanceReason «для первой строки холодного письма») уже
реализованы. Не хватает последней мили: автогенерация письма по
docs/EMAIL_STYLE.md + отправка + цепочка follow-up (день 0 / 3 / 7 — 80%
ответов приходит со 2–3 касания). Технически: слать НЕ с directport.ru
(отдельный прогретый домен, SPF/DKIM/DMARC, 20–50 писем/день на ящик).
Юридически: массовые рассылки без согласия — риск по ст. 18 ФЗ «О рекламе»,
поэтому персонализированные письма конкретным должностям малыми партиями.

**5. Telegram Ads.** Таргет на каналы про ВЭД, Китай, маркетплейсы. CTA ведёт
прямо в бота — человек не покидает мессенджер. Вход через реселлеров (eLama
и т. п.) от ~50 тыс. ₽.

**6. White-label партнёрка — стратегический козырь.** Мультитенантность уже
построена: свой бот, свой домен кабинета, своя тема оформления. Консультант
по ВЭД, карго-компания или курс «импорт из Китая» получает сервис под своим
брендом с revenue share и приводит клиентов сам. Осталось: страница
«Партнёрам» + упрощённый onboarding.

### Полуавтоматические

**7. Мониторинг Telegram-чатов + ручные ответы.** Десятки живых чатов по ВЭД,
карго, Китаю, белому импорту для селлеров. Юзербот мониторит ключевые фразы
(«как рассчитать пошлину», «подскажите код ТН ВЭД», «сколько выйдет
растаможка») → уведомление → ручной полезный ответ с цифрами и ненавязчивым
упоминанием бота. Доступ к людям в момент боли. Только вручную — автопостинг
убивает репутацию в чатах.

**8. Контент с автогенерацией.** Свой TG-канал: изменения ставок, новые волны
«Честного знака», утильсбор — данные уже в системе, генерацию можно
автоматизировать, публиковать с ревью. Плюс статьи руками: VC.ru (кейс
«контейнер на 480 позиций за 12 минут — показываю файл»), Хабр (техническая:
как AI классифицирует ТН ВЭД), Дзен.

**9. Вебинар-демо.** «Пришлите прайс — растаможим в прямом эфире за 10 минут»
для селлерских клубов и логистических комьюнити.

### Полностью ручные

**10. «Работа вперёд» вместо питча — главная замена звонкам.** Взять лид из
discovery, посмотреть сайт, собрать типовой прайс его товаров, прогнать через
pipeline и отправить готовый Excel: «Сделал расчёт по типовым товарам вашего
профиля — вот файл. Реальный прайс посчитаю бесплатно, первые 50 позиций».

**11. Тёплые списки вместо холодных.** Реестр таможенных представителей ФТС
(публичный, с контактами). Компании с открытыми вакансиями «декларант» /
«специалист ВЭД» на hh.ru — у них боль объёма прямо сейчас. Списки экспонентов
профильных выставок.

**12. Выставки ногами.** TransRussia (март), таможенные форумы, селлерские
конференции (WBCON и подобные). Стенд не нужен — билет посетителя и QR-код
бота. Один день = 30–50 разговоров с ЛПР, недоступными по телефону.

**13. Партнёрства руками.** Курсы по ВЭД и «импорту из Китая» (студентам —
инструмент, авторам — партнёрка), 1С-франчайзи и бухфирмы с
клиентами-импортёрами, малые таможенные брокеры (сервис для них не конкурент,
а ускоритель — особенно с выгрузкой в их ПО).

Если звонки продолжать: звонить не в приёмные, а конкретным людям (малые
брокеры, карго — трубку берёт владелец), и не с предложением, а с «я уже
сделал для вас расчёт, куда прислать?». Но для этого продукта звонки — худший
канал: асинхронные касания с приложенным результатом работают лучше.

## Приоритетный план (30–60 дней)

1. **Сейчас:** переупаковать оффер во всех касаниях: «пришлите инвойс — вернём
   готовый расчёт сегодня, первые 50 позиций бесплатно».
2. **Неделя 1:** discovery по 3–5 городам/нишам → 100–200 лидов со
   score ≥ 0,8 → 10–15 персональных писем в день (через /email, с персональной
   ссылкой-приглашением — атрибуция уже работает) + follow-up через 3 и 7 дней.
   Для топ-20 лидов — «работа вперёд» с готовым Excel.
3. **Неделя 2–3:** тест Яндекс.Директа; вступить в 20–30 профильных чатов и
   начать отвечать; публичный мини-калькулятор на лендинг.
4. **Месяц 2:** программатик-SEO страницы, TG-канал, первая статья-кейс на VC.
5. **Месяц 2–3:** страница «Партнёрам», первые 2–3 white-label партнёра.

**Метрика первого месяца** — не «продажи», а компании, приславшие реальный
прайс (activation). Цель — 10. Кто увидел свой Excel — тому продавать почти
не нужно.

## Внутренние инструменты для маркетинга (уже в продукте)

- **Leads-модуль** (super_admin, раздел «Лиды» в админке): AI-discovery
  компаний через web_search + AI-enrichment (контакты, ИНН, relevanceScore,
  relevanceReason для первой строки письма).
- **Атрибуция конверсии:** персональная ссылка-приглашение
  `t.me/<bot>?start=lead_<id>` на карточке лида — перешедший клиент
  автоматически привязывается к лиду.
- **Email-инфраструктура:** docs/EMAIL_STYLE.md (правила писем) +
  `pnpm lint-email` (линт типографики), скилл /email для генерации.
- **Free-50:** welcome-бонус 50 позиций начисляется каждому новому клиенту
  автоматически.
- **White-label:** мультитенантность (свой бот, домен, тема) — готовая база
  партнёрской программы.
- **Лендинг** ru/en/zh с офферами и деливераблами.

## Профиль помощника по продвижению

Кого искать в первую очередь: маркетолог-универсал / growth-специалист,
который возьмёт исполнение каналов руками.

- Задачи: Директ + Telegram Ads, контент (канал, статьи, кейсы), комьюнити
  (профильные чаты), партнёрские каналы, участие в email-outbound.
- Опыт в B2B, логистике или ВЭД — сильный плюс, но важнее хваткость и
  самостоятельность: план каналов есть (этот документ), нужен исполнитель
  с головой.
- Формат гибкий: парт-тайм / проектно / партнёрство — по договорённости.
